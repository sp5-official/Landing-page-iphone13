# 🍎 iPhone 13 Landing Page Clone

A clean, modern, and responsive landing page for the **iPhone 13**, developed using **HTML5** and **CSS3**.
This project replicates the design aesthetics of Apple's official product page and was created as part of a web development internship task by **PRODIGY INFOTECH**.

🔗 **Live Demo**: https://sp5-official.github.io/Landing-page-iphone13/

---

## 📖 Project Description

This is a front-end-only project that mimics a product landing page, focusing on layout design, responsive UI/UX, and clean code structure. 
he landing page presents key highlights of the iPhone 13, promotional imagery, and a compelling call to action.

This clone is intended to showcase the following:

- Semantic HTML structure
- Pixel-perfect UI replication
- Responsive layout with Flexbox and Media Queries
- Styling and spacing using modern CSS techniques

---

## 🧩 Key Features

- ✅ **Hero Section**: Includes a large featured product image, main headline, and call-to-action buttons.
- ✅ **Highlights Section**: Presents product features like the A15 Bionic chip, camera system, and display.
- ✅ **Responsive Design**: Looks great on mobile, tablet, and desktop screens.
- ✅ **Clean Code**: Modular CSS and well-indented HTML for easy readability.

---

## 🛠 Technologies Used

**HTML5**: Structure and semantic content
**CSS3**: Styling, layout, responsive design
**Flexbox**: For layout and alignment
**Media Queries**: To adapt layout across screen sizes
**Google Fonts (optional)**: Custom typography
